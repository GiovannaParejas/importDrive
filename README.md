# Import Drive - Locação de Carros Importados

Projeto individual da turma **1ESPI** desenvolvido com **React + Vite + Tailwind CSS** e **React Router DOM**.

## Link Repositório
https://github.com/GiovannaParejas/importDrive

## Link Vercel
https://import-drive.vercel.app/

## Estrutura

```
src/
├── components/
│   ├── Home/
│   │   ├── Destaques.jsx
│   │   ├── Hero.jsx
│   │   ├── Vantagens.jsx
│   │   └── VantagensCard.jsx
│   ├── Navbar.jsx
│   ├── Footer.jsx
│   └── Card.jsx
├── pages/
│   ├── Home.jsx
│   └── Carros.jsx
├── data/
│   └── carros.js
├── App.jsx      
├── main.jsx
└── index.css    
```

## Rotas

| Rota      | Página |
|-----------|--------|
| `/`       | Home   |
| `/carros` | Carros |

## Como rodar

```bash
npm install
npm run dev
```
